## Features to Test

### ✨ Core Features

- **Browse Events**: View all nearby events based on your location
- **Create Event**: Add your own events to the platform
- **Event Details**: View complete information including maps
- **Search**: Filter events by title
- **AI City Guide**: Get AI-powered recommendations for events in any city

### 🎨 Premium UI Elements

- Smooth animations and transitions
- Glass morphism design
- 3D card effects with hover interactions
- WebGL-based image trail on mouse movement
- Animated gradient text
- Interactive galaxy background

### 📱 Pages to Explore

1. **Home** - Hero section with TypeAnimation
2. **Events** - Browse all events with advanced search
3. **My Events** - View and manage your created events
4. **Create Event** - Premium form with location autocomplete
5. **Event Details** - Detailed view with interactive map
6. **AI Guide** - AI-powered city event recommendations
